Topic 1 संगणक रचना (Computer Architecture)

सुरुवातीची रचना (Fundamentals of Architecture):*

Deep Dive

मेमरी एकके (Memory Units)

एकक (Unit) किंमत (Value)
Bit (बिट) 0 किंवा 1 (सर्वात लहान एकक)
Nibble (निबल) 4 बिट्स
Byte (बाइट) 8 बिट्स (1 अक्षर)
KB (किलोबाइट) 1024 बाइट्स
MB (मेगाबाइट) 1024 KB
GB (गिगाबाइट) 1024 MB
TB (टेराबाइट) 1024 GB

सुरुवातीची रचना (Fundamentals of Architecture):

आधुनिक संगणक वॉन न्यूमॅन आर्किटेक्चर (Von Neumann Architecture) वर आधारित आहेत, ज्यामध्ये CPU, मेमरी आणि I/O उपकरणे एका बस (Bus) द्वारे जोडलेली असतात. CPU Fetch-Decode-Execute चक्रावर काम करतो: तो मेमरीमधून सूचना मिळवतो (fetch), त्याचा अर्थ लावतो (decode), आणि नंतर ती पार पाडतो (execute).

प्राथमिक विरुद्ध दुय्यम मेमरी (Primary vs. Secondary Memory):

RAM (रँडम ऍक्सेस मेमरी) ही अस्थिर (volatile) प्राथमिक मेमरी आहे (पॉवर बंद झाल्यावर डेटा जातो), जी सध्या चालू असलेल्या प्रोग्राम्ससाठी वापरली जाते. ROM (रीड ओन्ली मेमरी) ही स्थिर (non-volatile) असते आणि त्यात BIOS/बूट सूचना असतात. हार्ड ड्राइव्ह आणि SSD हे दुय्यम स्टोरेज आहेत जे डेटा कायमस्वरूपी साठवतात.

Topic 2 हार्डवेअर आणि सॉफ्टवेअर (Hardware & Software)

सॉफ्टवेअरचे प्रकार*

Deep Dive

सॉफ्टवेअरचे प्रकार

  • System Software: OS (Windows, Linux, Android), कंपाईलर्स, इंटरप्रिटर.

  • Application Software: एमएस ऑफिस, फोटोशॉप, वेब ब्राउझर.

  • Utility Software: अँटीव्हायरस, फाइल कम्प्रेशन (WinZip), डिस्क डीफ्रॅग.

  • Open Source (मोफत कोड): लिनक्स, अँड्रॉइड, मोझिला फायरफॉक्स.

  • Proprietary (विकतचे): विंडोज, MacOS, एमएस ऑफिस.

सॉफ्टवेअर वर्गीकरण (Software Classification):

सॉफ्टवेअर हा सूचनांचा संच आहे जो हार्डवेअरला काय करायचे हे सांगतो. System Software हा आधार स्तर आहे (उदा. OS) जो हार्डवेअर संसाधने व्यवस्थापित करतो. Application Software सिस्टम सॉफ्टवेअरच्या वर चालतो आणि वापरकर्त्यासाठी विशिष्ट कार्ये करतो (उदा. टायपिंग करणे).

अनुवादक (Compiler vs Interpreter):

संगणक फक्त मशीन कोड (0 आणि 1) समजतात. हाय-लेव्हल कोडचे भाषांतर करणे आवश्यक आहे.

• Compiler: संपूर्ण प्रोग्रामचे एकाच वेळी भाषांतर करतो → एक एक्झिक्युटेबल फाईल बनवतो. (उदा. C, C++).

• Interpreter: कोडचे ओळीने-ओळ (line-by-line) भाषांतर करतो → त्वरित अंमलबजावणी करतो. (उदा. Python, JavaScript).

Topic 3 नेटवर्किंग आणि इंटरनेट (Networking & Internet)

इंटरनेटची मूलतत्त्वे (Internet Basics):*

Deep Dive

इंटरनेटची मूलतत्त्वे (Internet Basics):

इंटरनेट हे नेटवर्क्सचे एक विशाल जाळे (WAN) आहे. ते क्लायंट-सर्व्हर मॉडेल (Client-Server Model) वर कार्य करते, जिथे तुमचे डिव्हाइस (क्लायंट) डेटाची विनंती करते आणि एक शक्तिशाली संगणक (सर्व्हर) तो परत पाठवतो.

OSI मॉडेल (Open Systems Interconnection):

नेटवर्क परस्परसंवाद समजून घेण्यासाठी वापरली जाणारी एक संकल्पनात्मक चौकट. याचे 7 थर (Layers) आहेत:

  1. Physical (केबल्स)

  2. Data Link (MAC पत्ता)

  3. Network (IP पत्ता/राउटर)

  4. Transport (TCP/UDP)

  5. Session

  6. Presentation (एनक्रिप्शन)

  7. Application (HTTP/ब्राउझर).

Topic 4 शॉर्टकट कीज (Shortcut Keys)

F1: Help (मदत)

Deep Dive

फंक्शन कीज (Function Keys)

  • F1: Help (मदत)

  • F2: Rename / Edit Cell (नाव बदला)

  • F5: Refresh / Slideshow (रिफ्रेश)

  • F7: Spell Check (शब्दलेखन तपासणी)

  • F11: Full Screen (पूर्ण स्क्रीन)

  • F12: Save As (सेव्ह ऍझ)

  • Alt + F4: Close Window (बंद करा)

  • Win + D: Show Desktop (डेस्कटॉप)

शॉर्टकट श्रेण्या (Shortcut Categories):

• Navigation: Home (ओळीची सुरुवात), End (ओळीचा शेवट), Ctrl + Home (दस्तऐवजाची सुरुवात), Ctrl + End (दस्तऐवजाचा शेवट).

• Formatting: Ctrl + B (बोल्ड), Ctrl + I (इटॅलिक), Ctrl + U (अंडरलाइन), Ctrl + J (जस्टिफाय).

• Browser: Ctrl + T (नवीन टॅब), Ctrl + W (टॅब बंद करा), Ctrl + Shift + T (बंद टॅब पुन्हा उघडा).

Topic 5 संक्षिप्त रूपे (Abbreviations)

BIOS:* Basic Input Output System

Deep Dive

BIOS: Basic Input Output System USB: Universal Serial Bus PDF: Portable Document Format HTTP: HyperText Transfer Protocol HTML: HyperText Markup Language WiFi: Wireless Fidelity VIRUS: Vital Information Resources Under Siege GUI: Graphical User Interface JPEG: Joint Photographic Experts Group VPN: Virtual Private Network UPS: Uninterruptible Power Supply

संक्षिप्त रूपांचे महत्त्व (Importance of Abbreviations):

संगणक विज्ञानात संक्षिप्त रूपे सर्वत्र आहेत. ते जाणून घेणे केवळ परीक्षांसाठीच नव्हे तर तांत्रिक वैशिष्ट्ये समजून घेण्यासाठी देखील महत्त्वाचे आहे. उदाहरणार्थ, HTTP (असुरक्षित) आणि HTTPS (सुरक्षित) यातील गोंधळ टाळणे ही एक मोठी सुरक्षा संकल्पना आहे. तसेच, BIOS चे ज्ञान बूट समस्यांचे निवारण करण्यास मदत करते.
