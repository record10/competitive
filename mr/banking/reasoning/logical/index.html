लॉजिकल रीजनिंग

सिलोगिझम आणि असमानता

IBPS PO Pre SBI Clerk Pre

सिलोगिझम कीवर्ड:

  • Only A is B: सर्व B हे A आहेत।

  • Only a few A are B: काही A, B आहेत आणि काही A, B नाहीत।

असमानता गेट पद्धत:

  • >: डावीकडून उघडे गेट।

  • <: डावीकडून बंद गेट।

  • =: दोन्ही बाजूंनी उघडे।

Deep Dive

1. सिलोगिझम (Only A Few सापळा) "Only a few A are B" = काही A, B आहेत + काही A, B नाहीत।

शक्यता: सर्व A, B असू शकतात? नाही। सर्व B, A असू शकतात? होय।

2. कोडेड असमानता मॅजिक बॉक्स: > (वर डावीकडे), >= (खाली डावीकडे), < (वर उजवीकडे), <= (खाली उजवीकडे), = (मध्य)।

3. क्रम आणि रँकिंग T = (डावे स्थान + उजवे स्थान) - 1.

मशीन इनपुट आणि कोडिंग

इनपुट-आउटपुट तर्क:

  • शिफ्टिंग: सिंगल किंवा डबल।

  • संख्या (चढता/उतरता), शब्द (वर्णमाला क्रम)।

कोडिंग-डिकोडिंग:

  • चायनीज कोडिंग: सामान्य शब्द शोधा।

  • नवीन पॅटर्न: तर्काने मिळवलेले चिन्ह।

Deep Dive

1. मशीन इनपुट-आउटपुट सुवर्ण नियम: पूर्ण शब्द लिहू नका। आद्याक्षरे वापरा।

2. चायनीज कोडिंग प्रिलिम्समध्ये मोफत गुण। लाईनमध्ये शब्द जुळवा।

3. नवीन पॅटर्न कोडिंग कोड 3 भागांत तोडा: संख्या, चिन्ह, अक्षर।
