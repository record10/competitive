अंकगणित

अंकगणित

शेकडेवारी (Percentage)

IBPS PO Pre SBI Clerk Mains

मूळ व्याख्या: टक्केवारी/शेकडेवारी म्हणजे "प्रति 100". हा 100 छेद (denominator) असलेला अपूर्णांक आहे.

  • X चे Y% = Y चे X% (Commutative Property)

  • अपूर्णांक ते %: 100 ने गुणा. (उदा., 1/2 * 100 = 50%)

  • % ते अपूर्णांक: 100 ने भागा. (उदा., 20% = 20/100 = 1/5)

महत्त्वाचे अपूर्णांक (लक्षात ठेवा):

  • 1/2 = 50%

  • 1/3 = 33.33%

  • 1/4 = 25%

  • 1/5 = 20%

  • 1/6 = 16.66%

  • 1/8 = 12.5%

  • 1/9 = 11.11%

  • 1/11 = 9.09%

Deep Dive

1. शेकडेवारीच्या मूलभूत संकल्पना शेकडेवारी हा अंकगणिताचा कणा आहे. टक्केवारीच्या गणनेवर मजबूत पकड तुम्हाला डेटा इंटरप्रिटेशन (DI), नफा आणि तोटा, सरळ आणि चक्रवाढ व्याज (SI/CI), आणि गुणोत्तर व प्रमाण (Ratio & Proportion) मध्ये मदत करते.

आधार (Base) ची संकल्पना: कोणत्याही शेकडेवारीच्या प्रश्नामध्ये, आधार (Base) ओळखणे महत्त्वाचे असते. आधार ती किंमत आहे ज्याशी तुलना केली जाते. उदाहरण: "A चा पगार B पेक्षा 20% जास्त आहे". येथे, B हा आधार आहे. समजा B = 100. मग A = 100 + 100 चे 20% = 120.

2. महत्त्वाचे नियम आणि शॉर्टकट

नियम 1: टक्केवारीतील बदलाची संकल्पना टक्केवारीतील बदल = [(अंतिम मूल्य - प्रारंभिक मूल्य) / प्रारंभिक मूल्य] * 100. धन मूल्य (Positive) वाढ दर्शवते, तर ऋण मूल्य (Negative) घट दर्शवते.

नियम 2: क्रमिक टक्केवारी बदल (Successive Percentage Change) जर एखाद्या मूल्यात प्रथम x% आणि नंतर y% बदल झाला, तर निव्वळ बदल: निव्वळ बदल = x + y + (xy/100) % (बीजगणितीय चिन्हांचा काटेकोरपणे वापर करा. जर x घट असेल, तर -x वापरा.)

नियम 3: गुणाकार स्थिरता (व्यस्त प्रमाण) जर A * B = स्थिरांक (Constant), तर A हे B च्या व्यस्त प्रमाणात असते. सूत्र: जर A मध्ये R% वाढ झाली, तर B मध्ये [R/(100+R) * 100]% घट होते. उपयोग: किंमत * खप = खर्च. (जर किंमत वाढली, तर खप कमी होतो)

3. लोकसंख्या आणि घसारा (Depreciation) समस्या लोकसंख्या सूत्र: जर सध्याची लोकसंख्या P आहे आणि ती वार्षिक R% दराने वाढत आहे:

  • n वर्षांनंतरची लोकसंख्या = P * (1 + R/100)^n
  • n वर्षांपूर्वीची लोकसंख्या = P / (1 + R/100)^n

घसारा (Depreciation): मशीन्स/संपत्तीसाठी, किंमत कमी होते. (1 - R/100)^n वापरा.

नफा आणि तोटा (Profit & Loss)

IBPS PO Pre SBI PO Pre

मूलभूत शब्दावली:

  • CP (Cost Price): खरेदी किंमत.

  • SP (Selling Price): विक्री किंमत.

  • नफा (Profit): SP - CP (जर SP > CP).

  • तोटा (Loss): CP - SP (जर CP > SP).

महत्त्वाचे सूत्र:

  • नफा % = (नफा / CP) * 100

  • तोटा % = (तोटा / CP) * 100

  • SP = CP * (100 + नफा %)/100

  • MP (Marked Price): छापील किंमत.

  • सवलत (Discount) नेहमी छापील किमतीवर (MP) असते.

Deep Dive

1. CP-SP-MP साखळी समजून घेणे CP (खरेदी किंमत) --> वाढवणे (+%) --> MP (छापील किंमत) --> सूट (-%) --> SP (विक्री किंमत)

2. अप्रामाणिक दुकानदार समस्या दुकानदार खोट्या वजनांचा वापर करून फसवणूक करतो. नफा % = [(खरे वजन - खोटे वजन) / खोटे वजन] * 100 टीप: नफा हा दुकानदार प्रत्यक्षात काय देतो (खोटे वजन) यावर मोजला जातो.

3. क्रमिक सूट (Successive Discounts) जर D1% आणि D2% ची दोन क्रमिक सूट दिली असेल: निव्वळ सूट = D1 + D2 - (D1 * D2)/100 % उदाहरण: 50% आणि 50% च्या दोन सलग सवलती म्हणजे 75% सूट.

4. समान विक्री किंमत (Same SP) नियम जर दोन वस्तू समान विक्री किमतीवर (SP) विकल्या गेल्या, आणि एक x% नफ्यावर आणि दुसरी x% तोट्यावर, तर नेहमी निव्वळ तोटा होतो. तोटा % = (x / 10)^2 %

सरळ आणि चक्रवाढ व्याज (SI & CI)

IBPS PO Mains SBI PO Mains

सरळ व्याज (SI):

  • व्याज दरवर्षी समान राहते.

  • केवळ मुद्दलावर मोजले जाते.

  • SI = (P * R * T) / 100

  • रास (Amount) = P + SI

चक्रवाढ व्याज (CI):

  • व्याजावर व्याज.

  • वेगाने (घातांकीय) वाढते.

  • A = P * (1 + R/100)^T

  • CI = रास - मुद्दल

Deep Dive

1. फरक समजून घेणे सरळ व्याज रेषीय वाढ (linear growth) आहे, तर चक्रवाढ व्याज घातांकीय वाढ (exponential growth) आहे. उदाहरण: 1000 वर 10%. वर्ष 1: SI=100, CI=100 वर्ष 2: SI=100, CI=110 वर्ष 3: SI=100, CI=121

2. CI साठी महत्त्वाच्या ट्रिक्स

72 चा नियम (Rule of 72): R% चक्रवाढ व्याजाने पैसे दुप्पट होण्यासाठी किती वर्षे लागतील: वर्षे ≈ 72 / R

फरक सूत्रे (थेट):

  • 2 वर्षांसाठी: Diff = P (R/100)^2
  • 3 वर्षांसाठी: Diff = P (R/100)^2 * (3 + R/100)

CI मध्ये हप्ते (Installments): P = X / (1 + R/100) + X / (1 + R/100)^2

काळ आणि काम (Time & Work)

IBPS PO Pre SBI Clerk Pre

मूल संकल्पना:

  • एकूण काम = कार्यक्षमता * वेळ.

  • कार्यक्षमता वेळेच्या व्यस्त प्रमाणात असते.

  • मानलेले एकूण काम = दिवसांचा लसावी (LCM).

सूत्रे:

  • M1D1H1/W1 = M2D2H2/W2 (साखळी नियम).

  • जर A x दिवस घेतो आणि B y दिवस घेतो: एकत्रित वेळ = (xy)/(x+y).

Deep Dive

1. LCM पद्धत (सर्वोत्तम दृष्टिकोन) अपूर्णांकांऐवजी, कामाचे एकूण युनिट (LCM) गृहीत धरा. उदाहरण: A=10 दिवस, B=15 दिवस. LCM=30 युनिट्स. A कार्यक्षमता = 3, B कार्यक्षमता = 2. एकत्रित = 5. वेळ = 30/5 = 6 दिवस.

2. साखळी नियम (MDH सूत्र) (M1 * D1 * H1) / W1 = (M2 * D2 * H2) / W2 जेथे M=पुरुष, D=दिवस, H=तास, W=काम.

3. नळ आणि टाकी (Pipes & Cisterns) काळ आणि काम सारखीच संकल्पना. गळती/आउटलेट पाइपची कार्यक्षमता ऋण (Negative) असते. निव्वळ कार्यक्षमता = इनलेट - आउटलेट.

4. कार्यक्षमता गुणोत्तर समस्या जर A हा B पेक्षा दुप्पट चांगला असेल: कार्यक्षमता गुणोत्तर -> A:B = 2:1 वेळ गुणोत्तर -> A:B = 1:2
