Syllogism & Inequality

IBPS PO Pre SBI Clerk Pre

Syllogism Keywords:

  • Only A is B: Means All B is A (and B cannot touch anyone else).

  • Only a few A are B: Means "Some A are B" AND "Some A are NOT B".

  • Can never be: Definite Negative relation.

Inequality "Gate" Method:

  • >: Open Gate from left.

  • <: Closed Gate from left.

  • =: Open from both sides (Mat), requires "=" at every step.

  • To travel from A to B, all gates must be open.

Deep Dive

1. Syllogism (The "Only A Few" Trap) Modern banking exams focus heavily on "Only a few". Concept: "Only a few A are B" combines two statements:

  1. Some A are B.
  2. Some A are NOT B. Venn Diagram: Draw two intersecting circles A and B. Put a dot in A's non-intersecting part and cross it with B meaning "This part of A can never go to B".

Possibility Cases: • All A can be B? If "Only a few A are B" is true, then NO. Because "Some A are NOT B" is definite. • All B can be A? YES. The restriction is from A to B, not B to A.

2. Coded Inequality In Mains, inequalities come in coded form (e.g., A @ B means A > B). Magic Box Trick: Draw a box. Place > (Top Left), >= (Bottom Left), < (Top Right), <= (Bottom Right), = (Center). If relation is between diagonal elements (e.g., > and <=), the answer is always CND (No Relation).

3. Order & Ranking Formula for Total People (T): T = (Left Position + Right Position) - 1. Between Case: If T > (L + R) => Simple case. Between = T - (L + R). If T < (L + R) => Overlap case. Between = (L + R) - T - 2.

Machine Input & Coding

IBPS PO Mains SBI PO Mains

Input-Output Logic:

  • Shifting: Single-shifting (Left/Right) or Double-shifting.

  • Operations: Numbers (Asc/Desc, Sum of digits, Odds/Evens). Words (Alpha order, Vowels/Consonants).

Coding-Decoding Types:

  • Chinese Coding: "Sky is Blue" -> "la pa ma". (Find common words).

  • New Pattern (Mains): Symbols/Numbers derived from logic (e.g., Last Letter + 2).

Deep Dive

1. Machine Input-Output This topic is strictly for Mains. A machine rearranges an input line into steps based on specific preset rules. Golden Rule: Never write the full words in steps. Use initials (A, B, C) or numbers. Logic Identification (Within 2 mins): Look at the FINAL STEP first. Is it sorted? Alternating? Look at Step 1 to Step 2 change. Is it shifting inward or outward?

Box Type Input (New Pattern): Instead of lines, numbers are in boxes. Logic mostly involves: • Cross addition (Digit sum of Box 1 + Digit sum of Box last). • Multiplication of digits.

2. Chinese Coding (Substitution) This is the "Free Marks" topic in Prelims. Method: Write words of Line 1. For Line 2, write words below Line 1 words if same (use " marks). If new, write next to it. Do same for logic codes. Match the pattern.

3. New Pattern Coding Example: "Apple" is coded as "5@F". Decoding Strategy: Break the code into 3 parts: Number, Symbol, Letter. • Number: Often total letters, first/last letter rank, vowel count. • Symbol: Even/Odd length? Start with Vowel? • Letter: Reverse of last letter? +1 to first letter?

Blood Relations & Directions

IBPS PO Pre SBI Clerk Pre

Blood Relation Symbols:

  • Male: Square [ ] or (+).

  • Female: Circle ( ) or (-).

  • Spouse: Double line (=).

  • Sibling: Single line (—).

Direction & Shadows:

  • Morning (Sun in East): Shadow falls West.

  • Evening (Sun in West): Shadow falls East.

  • Pythagoras: Hypotenuse² = Base² + Height².

Deep Dive

1. Family Tree Method Never calculate relations in your head. Draw the tree. Generations: • Grandparents (Top) • Parents (Middle) • Children (Bottom) Example: "A is brother of B. B is daughter of C." Draw C on top. Draw B (circle) below C. Draw A (square) next to B with a single line.

2. Coded Blood Relations "P + Q means P is father of Q". Elimination Trick: Check Gender First! Question: Which shows M is daughter of N? Step 1: Look at options. Identify M's gender symbol. If option says "M x K" and 'x' means Brother, then M is Male. Reduce options immediately. Tip: "A is spouse of B". If A is Male, B is AUTOMATICALLY Female.

3. Shortest Distance (Pythagoras) Usually asked as "How far is he from starting point?". This is the Displacement (Straight line), not Total Distance. • If he moves 3km North, then 4km East. • Distance = 3 + 4 = 7km. • Shortest Distance = √(3² + 4²) = √(9+16) = √25 = 5km.
