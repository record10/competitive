Percentage

IBPS PO Pre SBI Clerk Mains

Core Definition: Percentage means "per 100". It is a fraction with denominator 100.

  • X% of Y = Y% of X (Commutative Property)

  • Fraction to %: Multiply by 100. (e.g., 1/2 * 100 = 50%)

  • % to Fraction: Divide by 100. (e.g., 20% = 20/100 = 1/5)

Key Fractions (Memorize):

  • 1/2 = 50%

  • 1/3 = 33.33%

  • 1/4 = 25%

  • 1/5 = 20%

  • 1/6 = 16.66%

  • 1/8 = 12.5%

  • 1/9 = 11.11%

  • 1/11 = 9.09%

Deep Dive

1. Basic Concepts of Percentage Percentage is the backbone of arithmetic. A strong command over percentage calculations helps in Data Interpretation (DI), Profit & Loss, Simple & Compound Interest (SI/CI), and Ratio & Proportion.

The Concept of Base: In any percentage problem, identifying the Base is crucial. The base is the value to which comparison is made. Example: "Salary of A is 20% more than B". Here, B is the base. Let B = 100. Then A = 100 + 20% of 100 = 120.

2. Important Rules & Shortcuts

Rule 1: Concept of Percentage Change Percentage Change = [(Final Value - Initial Value) / Initial Value] * 100. POSITIVE indicates increase, NEGATIVE indicates decrease.

Rule 2: Successive Percentage Change If a value changes by x% and then by y%, net change: Net Change = x + y + (xy/100) % (Use strict algebraic signs. If decrease, use -x).

Rule 3: Product Constancy (Inverse Proportionality) If A * B = Constant, then A is inversely proportional to B. Formula: If A increases by R%, B decreases by [R / (100 + R) * 100] %. Application: Price * Consumption = Expenditure.

3. Population & Depreciation Problems Population Formula: If current population is P and it increases at R% per annum:

  • Population after n years = P * (1 + R/100)^n
  • Population n years ago = P / (1 + R/100)^n

Depreciation: For machines/assets, value decreases. Use (1 - R/100)^n.

Profit & Loss

IBPS PO Pre SBI PO Pre

Basic Terms:

  • CP: Cost Price (Buying Price).

  • SP: Selling Price.

  • Profit (P): SP - CP (if SP > CP).

  • Loss (L): CP - SP (if CP > SP).

Key Formulas:

  • P% = (Profit / CP) * 100

  • L% = (Loss / CP) * 100

  • SP = CP * (100 + P%)/100

  • MP: Marked Price (List/Tag Price).

  • Discount is ALWAYS on MP.

Deep Dive

1. Understanding the CP-SP-MP Chain CP (Cost Price) --> Markup (+%) --> MP (Marked Price) --> Discount (-%) --> SP (Selling Price)

2. Dishonest Shopkeeper Problems A shopkeeper cheats by using false weights. Profit % = [(True Weight - False Weight) / False Weight] * 100 Note: Profit is calculated on what the shopkeeper actually gives (False Weight), which is his cost investment.

3. Successive Discounts If two successive discounts of D1% and D2% are given, single equivalent discount is: Net Discount = D1 + D2 - (D1 * D2)/100 % Example: Two successive discounts of 50% is NOT 100%. Net = 50+50 - 25 = 75%.

4. Same SP Rule If two articles are sold at the same Selling Price (SP), and one is sold at x% profit and the other at x% loss, there is ALWAYS a net loss. Loss % = (x / 10)^2 %

SI & CI (Interest)

IBPS PO Mains SBI PO Mains

Simple Interest (SI):

  • Interest remains same every year.

  • Calculated only on Principal.

  • SI = (P * R * T) / 100

  • Amount = P + SI

Compound Interest (CI):

  • Interest on Interest.

  • Increases exponentially.

  • A = P * (1 + R/100)^T

  • CI = Amount - Principal

Deep Dive

1. Understanding the Difference Simple Interest is linear growth, while Compound Interest is exponential growth. Example: 10% on 1000. Year 1: SI=100, CI=100 (Same for 1st year) Year 2: SI=100, CI=110 (10% on 1100) Year 3: SI=100, CI=121 (10% on 1210)

2. Key Tricks for CI

Rule of 72: To find years to double money at R%: Years ≈ 72 / R

Difference Formulas (Direct):

  • For 2 Years: Diff = P (R/100)^2
  • For 3 Years: Diff = P (R/100)^2 * (3 + R/100)

Installments in CI: P = X / (1 + R/100) + X / (1 + R/100)^2 + ...

Time & Work

IBPS PO Pre SBI Clerk Pre

Basic Concept:

  • Total Work = Efficiency * Time.

  • Efficiency is inversely proportional to Time.

  • Assumed Total Work = LCM of days.

Formulas:

  • M1D1H1/W1 = M2D2H2/W2 (Chain Rule).

  • If A takes x days and B takes y days: Combined = (xy)/(x+y).

Deep Dive

1. LCM Method (The Best Approach) Instead of fractions, assume a total unit of work (LCM). Example: A=10 days, B=15 days. LCM=30 units. A Eff = 3 units/day, B Eff = 2 units/day. Combined = 5 units/day. Time = 30/5 = 6 days.

2. Chain Rule (MDH Formula) (M1 * D1 * H1) / W1 = (M2 * D2 * H2) / W2 where M=Men, D=Days, H=Hours, W=Work (or Wages).

3. Pipes & Cisterns Same concept as Time & Work. Only difference: Leakage/Outlet pipe has Negative Efficiency. Net Efficiency = Inlet Eff - Outlet Eff.

4. Efficiency Ratio Problems If A is twice as good as B: Efficiency Ratio -> A:B = 2:1 Time Ratio -> A:B = 1:2
