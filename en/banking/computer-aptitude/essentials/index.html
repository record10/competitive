Computer Essentials

History & Generations of Computer

RRB Clerk Mains

Generations:

  • 1st (1940-56): Vacuum Tubes (ENIAC). Binary.
  • 2nd (1956-63): Transistors. Assembly Language.
  • 3rd (1964-71): ICs (Integrated Circuits). High-level languages.
  • 4th (1971-Present): Microprocessors (VLSI). PC era.
  • 5th (Present-Future): AI & ULSI. Important Machines:
  • Abacus: First calculating device.
  • Pascaline: First mechanical calculator (Blaise Pascal).
  • Analytical Engine: Charles Babbage (Father of Computer).
Deep Dive

1. Pioneers of Computer • Charles Babbage (Father of Computer): Designed Difference Engine (1822) and Analytical Engine (1837) - the blueprint for modern computers. • Ada Lovelace (First Programmer): Wrote the first algorithm for Babbage's machine. • Alan Turing (Father of Modern CS): Formalized "algorithm" and "computation". Created Turing Test for AI. • John von Neumann: Proposed Stored Program Concept (von Neumann Architecture). • Blaise Pascal: Invented the Pascaline (1642), first mechanical calculator.', 2. Types of Computers Based on Size & Speed: • Super Computer: Most powerful (FLOPS). Examples: Frontier, Fugaku, PARAM. • Mainframe: High reliability, massive data handling. Used by Banks. • Mini Computer: Mid-range servers (obsolete). • Micro Computer: Desktops, Laptops, Tablets, Smartphones.

Based on Data Handling: • Analog: Continuous data (Speedometer, Thermometer). • Digital: Discrete data (0s and 1s). Modern computers. • Hybrid: Both (ICU monitors).

Hardware & Software Components

RRB PO Mains RBI Assistant Mains

Input/Output Devices:

  • Input: Keyboard, Mouse, Scanner, MICR, OCR, OMR.
  • Output: Monitor, Printer, Plotter, Speaker.
  • Both: Touchscreen, Modem, Headset, Fax. Memory Hierarchy (Fastest to Slowest):
  1. Registers (Inside CPU)
  2. Cache Memory (L1, L2, L3)
  3. RAM (Primary Memory)
  4. SSD/HDD (Secondary Memory)
Deep Dive

1. CPU (Central Processing Unit) The "Brain of Computer". Speed in GHz. • ALU (Arithmetic Logic Unit): Calculator part. Arithmetic (+, -, *, /) and Logical (>, <, =, AND, OR, NOT) operations. • CU (Control Unit): "Traffic Police". Fetches, decodes, and directs instructions. • MU (Registers): Temporary storage inside CPU. Accumulator, Program Counter, MAR.', 2. Memory Architecture Primary Memory (Volatile): • RAM: Data lost on power off. Types: SRAM (Cache), DRAM (Main Memory). • ROM: Non-volatile. Stores BIOS. Types: PROM, EPROM, EEPROM.

Secondary Memory (Non-Volatile): • Magnetic: HDD, Floppy, Magnetic Tape. • Optical: CD (700MB), DVD (4.7GB), Blu-ray (25GB+). • Flash: SSD, USB Drives, Memory Cards.', 3. Software Classification System Software: Operates hardware. Examples: Windows, Linux, Drivers, Firmware. Application Software: End-user tasks. Examples: MS Office, Chrome, Photoshop.
