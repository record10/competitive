Topic 1 MS Word, Excel, PowerPoint & Shortcuts

Common Shortcuts:

  • Ctrl + C/V/X: Copy/Paste/Cut.

  • Ctrl + Z/Y: Undo/Redo.

  • Ctrl + B/I/U: Bold/Italic/Underline.

  • F7: Spell Check.

  • Shift + F3: Change Case (Upper/Lower).

Deep Dive

File Extensions:

  • .docx: Word Document (XML format).

  • .xlsx: Excel Spreadsheet.

  • .pptx: PowerPoint Presentation.

  • .pdf: Portable Document Format.

Trick: Hyperlink Shortcut: It is Ctrl + K (Not H). Find & Replace is Ctrl + H.

1. Microsoft Word Internals

Microsoft Word is a word processor used for creating documents. Key interface components include:

  • Ribbon: The command bar containing multiple tabs (Home, Insert, Page Layout, etc.). Can be minimized with Ctrl + F1.

  • Status Bar: Located at the bottom; displays page count, word count, and zoom slider.

  • Rulers: Horizontal and vertical rulers help alignment. Toggle view from the View tab.

  • Watermark: Faint text/image behind page content (Design/Page Layout tab).

  • Gutter Margin: Extra margin added to the binding side of a page for printing.

  • Orientation: Portrait (Vertical) vs. Landscape (Horizontal). Default is Portrait.

2. Microsoft Excel Components & Formulas

An electronic spreadsheet for data organization and analysis.

  • Workbook vs. Worksheet: A workbook (file) contains multiple worksheets (pages). Default extension: .xlsx.

  • Cell Reference Types:

Relative: Changes when copied (A1).

  • Absolute: Remains fixed (uses $ sign, e.g., $A$1).

  • Mixed: One part fixed ($A1 or A$1).

  • Trace Precedents/Dependents: Auditing tools to see which cells affect or are affected by the active cell.

Key Functions:

  • =SUM(A1:A10): Adds values.

  • =AVERAGE(B1:B5): Calculates mean.

  • =COUNT(range): Counts cells with numbers.

  • =COUNTA(range): Counts non-empty cells.

  • =VLOOKUP(...): Vertical lookup for data search.

  • =CONCATENATE(text1, text2): Joins text strings.

  • =NOW(): Current date and time.

3. PowerPoint & Extensions

  • Slide Master: A template to apply consistent layout/formatting to all slides.

  • Transition vs. Animation:

  • Transition: Visual effect between slides.

  • Animation: Visual effect on elements (text/images) within a slide.

  • Views: Normal, Slide Sorter, Reading View, Slide Show (F5).

Important File Extensions:

.docx (Word) .xlsx (Excel) .pptx (PPT) .accdb (Access) .txt (Plain) .rtf (Rich Text) .csv (Comma Sep) .png/.jpg (Image)

Topic 2 DBMS & SQL Basics

Concepts:

  • DBMS: Software to manage data (e.g., Oracle, MySQL).

  • RDBMS: Relational DBMS (Uses Tables).

  • Primary Key: Unique ID for a record (No duplicates, Not Null).

  • Foreign Key: Links two tables.

Deep Dive

SQL Commands:

  • DDL: Define structure (CREATE, ALTER, DROP).

  • DML: Manipulate data (INSERT, UPDATE, DELETE).

  • DCL: Control access (GRANT, REVOKE).

Trick: ACID Properties: Atomicity, Consistency, Isolation, Durability (Crucial for transactions).

1. Database Management Systems (DBMS)

Software designed to store, retrieve, define, and manage data in a database.

  • Three-Level Architecture:

External Level (View): How users see the data.

  • Conceptual Level (Logical): What data is stored and relationships.

  • Internal Level (Physical): How data is actually stored on storage devices.

  • Data Models:

Hierarchical: Tree-like structure (Parent-Child).

  • Network: Graph structure (Many-to-Many).

  • Relational (RDBMS): Tables (Rows/Columns). Most common (SQL).

Keys in RDBMS

  • Primary Key (PK): Unique identifier for a record. Cannot be Null.

  • Candidate Key: A column eligible to become a Primary Key.

  • Alternate Key: Candidate keys not chosen as PK.

  • Foreign Key (FK): A field that links to the Primary Key of another table (creates relationship).

  • Super Key: Any set of attributes that uniquely identifies a row.

2. Normalization & ACID Properties

Normalization: The process of organizing data to minimize redundancy.

  • 1NF (First Normal Form): Eliminate repeating groups (atomic values).

  • 2NF (Second Normal Form): Eliminate partial dependency (Non-prime attribute dependent on part of a composite key).

  • 3NF (Third Normal Form): Eliminate transitive dependency (Non-prime attribute dependent on another non-prime attribute).

  • BCNF (Boyce-Codd NF): Stricter 3NF where for every dependency A → B, A must be a super key.

Transaction Properties (ACID):

Atomicity: "All or nothing" rule for transactions. Consistency: Database remains valid before/after transaction. Isolation: Transactions occur independently. Durability: Completed transactions are saved permanently.

3. SQL Commands (Structured Query Language)

Category Commands Purpose
DDL (Data Definition) CREATE, ALTER, DROP, TRUNCATE Defines database structure/schema. No rollback (usually).
DML (Data Manipulation) SELECT, INSERT, UPDATE, DELETE Manages data within tables. Can be rolled back.
DCL (Data Control) GRANT, REVOKE Controls user access and permissions.
TCL (Transaction Control) COMMIT, ROLLBACK, SAVEPOINT Manages transactions started by DML.
