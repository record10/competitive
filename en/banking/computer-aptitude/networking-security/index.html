Topic 1 Networking Basics & OSI Model

Network Types:

  • LAN: Local Area Network (Building).

  • MAN: Metropolitan Area Network (City).

  • WAN: Wide Area Network (Country/World).

  • PAN: Personal Area Network (Bluetooth).

Deep Dive

Topologies:

  • Bus: Single cable backbone.

  • Star: Central hub (Most common).

  • Ring: Token passing.

  • Mesh: Point-to-point (Most reliable).

Trick: OSI Layers: Please Do Not Throw Sausage Pizza Away (Physical, Data Link, Network, Transport, Session, Presentation, Application).

1. Network Types & Classifications

Computer networks are categorized based on their geographical scope and scale. Understanding these helps in designing appropriate infrastructure for different needs.

  • PAN (Personal Area Network): The smallest range network, centered around an individual (approx. 10 meters).

Wired: USB connections.

  • Wireless (WPAN): Bluetooth, ZigBee, Infrared. Example: Connecting headphones to a phone.

  • LAN (Local Area Network): Connects devices within a limited area like a home, office, or building.

High speed, low error rate, and ownership is usually private.

  • Technology: Ethernet (Wait) or Wi-Fi (WLAN).

  • MAN (Metropolitan Area Network): Covers a larger geographic area than a LAN, such as a city or a large campus.

It interconnects multiple LANs. Example: Cable TV network, City-wide Wi-Fi.

  • WAN (Wide Area Network): Spans a large physical distance, such as a country, continent, or the entire globe.

The Internet is the largest WAN. It uses leased telecommunication lines, satellites, or fiber optics.

  • SAN (Storage Area Network): A specialized, high-speed network that provides block-level network access to storage. It connects servers to data storage devices (tape libraries, disk arrays).

2. Network Topologies

Linear & Circular

  • Bus Topology: All devices are connected to a single central cable called the backbone.

Pros: Cheap, easy to install. Cons: If the backbone breaks, the whole network fails.

  • Ring Topology: Each device is connected to exactly two other devices, forming a circle. Data travels in one direction.

Cons: A failure in one node/cable breaks the loop (unless dual ring).

Complex Structures

  • Star Topology: All nodes connect to a central device (Hub/Switch).

Pros: Easy to troubleshoot. Failure of one node doesn't affect others. Most popular topology.

  • Mesh Topology: Devices are interconnected.

Full Mesh: Every device connects to every other device. Highest reliability & redundancy but expensive usage of cabling.

  • Tree Topology: Hierarchical structure (Star of Stars). Root node connects to other hubs.

3. The OSI Model (Open Systems Interconnection)

A conceptual framework used to understand network interactions, divided into 7 layers.

Layer Function Unit/Device
7. Application End-user interface. Services like email, file transfer. (HTTP, FTP, SMTP) Data
6. Presentation Data translation, encryption, decryption, and compression (JPEG, MPEG). Data
5. Session Establishes, maintains, and terminates connections (sessions). API handling. Data
4. Transport End-to-end delivery, flow control, error correction. (TCP - Reliable, UDP - Fast). Segments
3. Network Logical addressing (IP) and Routing (Path determination). Packets (Router)
2. Data Link Physical addressing (MAC), error detection. LLC and MAC sublayers. Frames (Switch/Bridge)
1. Physical Transmission of raw bitstream over physical medium (Cables, Wireless). Bits (Hub/Repeater)

Topic 2 Internet Protocols & Cyber Security

Protocols:

  • HTTP/HTTPS: Web browsing (S = Secure).

  • FTP: File Transfer Protocol.

  • SMTP: Simple Mail Transfer (Sending Email).

  • POP3/IMAP: Receiving Email.

Deep Dive

Malware Types:

  • Virus: Needs host/user action to spread.

  • Worm: Self-replicating (No host needed).

  • Trojan: Disguised as legitimate software.

  • Ransomware: Encrypts files & demands money.

Trick: Phishing vs Vishing vs Smishing: Phishing (Email), Vishing (Voice/Call), Smishing (SMS).

1. Key Internet Protocols & Ports

Protocols are rules that govern data communication. Ports are logical endpoints for connections.

  • HTTP (HyperText Transfer Protocol) - Port 80: Foundation of data communication for the WWW. Transmits data in plain text (unsecured).

  • HTTPS (HTTP Secure) - Port 443: Secure version of HTTP using SSL/TLS encryption. Essential for banking/shopping.

  • FTP (File Transfer Protocol) - Port 20/21: Used for transferring files between a client and a server.

  • SMTP (Simple Mail Transfer Protocol) - Port 25: Pushes email from client to server (sending).

  • POP3 (Post Office Protocol v3) - Port 110: Retrieves emails. Downloads and usually deletes from server.

  • IMAP (Internet Message Access Protocol) - Port 143: Retrieves emails. Manages email directly on the server (syncs across devices).

  • DNS (Domain Name System) - Port 53: The phonebook of the internet. Translates domain names (google.com) to IP addresses.

  • DHCP (Dynamic Host Configuration Protocol): Automatically assigns IP addresses to devices on a network.

  • Telnet (Port 23): Remote login (unsecured). Replaced by SSH (Secure Shell - Port 22).

2. IP Addressing (Identity of the Internet)

IPv4 vs IPv6

  • IPv4 (Internet Protocol version 4): 32-bit address, represented in dot-decimal notation (e.g., 192.168.1.1). Capable of approx 4.3 billion addresses (Exhausted).

Classes: Class A (Large networks), Class B (Medium), Class C (Small/Home), Class D (Multicast), Class E (Research).

  • IPv6 (Internet Protocol version 6): 128-bit address, represented in hexadecimal separated by colons (e.g., 2001:0db8::). Practically infinite address space to support IoT.

  • MAC Address: Media Access Control address. A 48-bit unique hardware identifier burnt into the Network Interface Card (NIC). It operates at Layer 2.

3. Cyber Threats & Malware

Types of Malware

  • Virus: Code that attaches itself to a legitimate program. Requires human action (running the program) to replicate and spread.

  • Worm: Standalone malware that replicates itself to spread to other computers. Requires no human action. Consumes network bandwidth.

  • Trojan Horse: Disguises itself as legitimate software (e.g., a free game) but performs malicious activity in the background. Does not replicate.

  • Ransomware: Encrypts the victim's data and demands payment (ransom) for the decryption key. (e.g., WannaCry).

  • Spyware: Secretly records user activity (keystrokes, passwords). Example: Keyloggers.

Common Attacks

  • Phishing: Fraudulent emails appearing to be from reputable sources to steal sensitive data.

Variations: Vishing (Voice/Phone), Smishing (SMS).

  • DDoS (Distributed Denial of Service): Flooding a target server with traffic from multiple compromised sources (Botnet) to make it unavailable to legitimate users.

  • Man-in-the-Middle (MitM): Attacker intercepts communication between two parties.

  • SQL Injection: Injecting malicious SQL code into a web form to manipulate the database.

4. Network Security Measures

  • Firewall: A network security device (hardware or software) that monitors and filters incoming and outgoing network traffic based on security policies. It creates a barrier between a trusted internal network and an untrusted external network (Internet).

  • VPN (Virtual Private Network): Encrypts your internet connection to hide your online activity and location. It creates a secure tunnel over a public network.

  • Encryption: Converting data into a code to prevent unauthorized access.

  • Symmetric: Same key for encryption and decryption.

  • Asymmetric (Public-Key): Different keys (Public to encrypt, Private to decrypt).
