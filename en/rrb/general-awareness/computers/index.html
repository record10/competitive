Computer Architecture

RRB NTPC RRB Group D RRB ALP RRB JE

CPU (Central Processing Unit): Brain.

  • ALU: Arithmetic/Logic (+, -, AND, OR).
  • CU (Control Unit): Nervous System (Decodes Key instructions).
  • Registers: Fastest memory. Memory Units:
  • Bit (0/1), Nibble (4 bits), Byte (8 bits).
  • KB (1024 Byte), MB (1024 KB), GB, TB.
Deep Dive

Basics of Architecture Modern computers are based on Von Neumann Architecture. It uses the stored program concept.

  • CPU Cycle: Fetch -> Decode -> Execute.

Computer Memory (Primary vs Secondary)

  • RAM (Random Access Memory): Primary memory. Volatile (Data lost when power off). (e.g., DDR4).
  • ROM (Read Only Memory): Non-volatile. Contains BIOS (Booting instructions).
  • Cache Memory: Buffer between CPU and RAM. Very fast.
  • Secondary Memory: HDD, SSD, Pen Drive (Permanent storage).

Hardware & Software

Input: Keyboard, Mouse, Scanner, MICR (Cheques), OCR, OMR, Joystick. Output: Monitor (VDU), Printer, Plotter, Speaker. Both: Touchscreen, Modem. Software Types:

  • System: OS (Windows, Linux), Compiler.
  • Application: MS Office, Browser.
  • Utility: Antivirus, WinZip.
  • Open Source: Linux, Android (Free).
Deep Dive

Software Classification Hardware is the body, Software is the soul.

  1. System Software: Operates computer hardware. (e.g., OS, Drivers).
  2. Application Software: Performs specific user tasks. (e.g., Word, Chrome).
  3. Utility Software: Maintenance. (e.g., Antivirus, Backups).

Language Translators Computer understands only Machine Language (0, 1).

  • Compiler: Converts entire high-level code (C++) to machine code at once. (Fast).
  • Interpreter: Translates code line-by-line (Python). (Easier debugging).
  • Assembler: Converts Assembly language to Machine language.

Networking & Internet

LAN: Local Area (Home/Office). WAN: Wide Area (Internet). IP Address: Internet Protocol (IPv4 32-bit, IPv6 128-bit). DNS: Domain Name System (Phonebook of Internet - maps URL to IP). Protocol: Rules. HTTP (Web), FTP (File), SMTP (Email). Modem: Analog-Digital converter. Topology: Bus, Star, Ring, Mesh.

Deep Dive

Networking Models (OSI Model) There are 7 layers of network communication:

  1. Physical: Transmission of bits (Cables, Hub).
  2. Data Link: MAC Address, Switch.
  3. Network: IP Address, Router (Sends packets).
  4. Transport: Guarantee of data delivery (TCP/UDP).
  5. Session: Session management.
  6. Presentation: Encryption/Decryption (JPEG, MP3).
  7. Application: User Interface (HTTP, FTP, Email).

Key Terminology

  • IP Address: Address of the computer. IPv4 (32-bit) and IPv6 (128-bit).
  • DNS (Domain Name System): Converts website names (google.com) to IP addresses (like a phonebook).
  • URL: Uniform Resource Locator (Web Address).
