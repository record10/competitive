Topic 1 कंप्यूटर वास्तुकला (Computer Architecture)

वास्तुकला के मूल सिद्धांत (Fundamentals of Architecture):*

Deep Dive

मेमोरी यूनिट्स (Memory Units)

इकाई (Unit) मूल्य (Value)
Bit (बिट) 0 या 1 (सबसे छोटी इकाई)
Nibble (निबल) 4 बिट्स
Byte (बाइट) 8 बिट्स (1 कैरेक्टर)
KB (किलोबाइट) 1024 बाइट्स
MB (मेगाबाइट) 1024 KB
GB (गीगाबाइट) 1024 MB
TB (टेराबाइट) 1024 GB

वास्तुकला के मूल सिद्धांत (Fundamentals of Architecture):

आधुनिक कंप्यूटर वॉन न्यूमैन आर्किटेक्चर (Von Neumann Architecture) पर आधारित हैं, जिसमें CPU, मेमोरी और I/O डिवाइस एक बस (Bus) के माध्यम से जुड़े होते हैं। CPU Fetch-Decode-Execute चक्र पर काम करता है: यह मेमोरी से निर्देश प्राप्त करता है (fetch), उसे समझता है (decode), और फिर उसे निष्पादित करता है (execute)।

प्राथमिक बनाम द्वितीयक मेमोरी (Primary vs. Secondary Memory):

RAM (रैंडम एक्सेस मेमोरी) अस्थिर (volatile) प्राथमिक मेमोरी है (पावर बंद होने पर डेटा खो जाता है), जिसका उपयोग वर्तमान में चल रहे प्रोग्रामों के लिए किया जाता है। ROM (रीड ओनली मेमोरी) गैर-अस्थिर (non-volatile) है और इसमें BIOS/बूट निर्देश होते हैं। हार्ड ड्राइव और SSD द्वितीयक भंडारण हैं जो डेटा को स्थायी रूप से सुरक्षित रखते हैं।

Topic 2 हार्डवेयर और सॉफ्टवेयर (Hardware & Software)

सॉफ्टवेयर के प्रकार*

Deep Dive

सॉफ्टवेयर के प्रकार

  • System Software: OS (विंडोज, लिनक्स, एंड्रॉइड), कंपाइलर, इंटरप्रेटर, असेंबलर।

  • Application Software: एमएस ऑफिस, फोटोशॉप, वेब ब्राउज़र।

  • Utility Software: एंटीवायरस, फाइल कम्प्रेशन (WinZip), डिस्क डीफ्रैग।

  • Open Source (मुफ्त कोड): लिनक्स, एंड्रॉइड, मोज़िला फ़ायरफ़ॉक्स।

  • Proprietary (पेड/बंद): विंडोज, मैकओएस, एमएस ऑफिस।

सॉफ्टवेयर वर्गीकरण (Software Classification):

सॉफ्टवेयर निर्देशों का एक सेट है जो हार्डवेयर को बताता है कि क्या करना है। System Software आधार परत है (जैसे OS) जो हार्डवेयर संसाधनों का प्रबंधन करता है। Application Software सिस्टम सॉफ्टवेयर के ऊपर चलता है और उपयोगकर्ता के लिए विशिष्ट कार्य करता है (जैसे दस्तावेज़ टाइप करना)।

अनुवादक (Compiler vs Interpreter):

कंप्यूटर केवल मशीनी कोड (0 और 1) समझते हैं। हाई-लेवल कोड का अनुवाद करना आवश्यक है।

• Compiler: पूरे प्रोग्राम का एक साथ अनुवाद करता है → एक एग्जीक्यूटेबल बनाता है। (उदाहरण: C, C++)।

• Interpreter: कोड का लाइन-दर-लाइन अनुवाद करता है → तुरंत निष्पादित करता है। (उदाहरण: Python, JavaScript)।

Topic 3 नेटवर्किंग और इंटरनेट (Networking & Internet)

इंटरनेट की मूल बातें (Internet Basics):*

Deep Dive

इंटरनेट की मूल बातें (Internet Basics):

इंटरनेट नेटवर्कों का एक विशाल नेटवर्क (WAN) है। यह क्लाइंट-सर्वर मॉडल (Client-Server Model) पर काम करता है, जहां आपका डिवाइस (क्लाइंट) डेटा का अनुरोध करता है और एक शक्तिशाली कंप्यूटर (सर्वर) उसे वापस भेजता है।

OSI मॉडल (Open Systems Interconnection):

नेटवर्क इंटरैक्शन को समझने के लिए उपयोग किया जाने वाला एक वैचारिक ढांचा। इसकी 7 परतें (Layers) हैं:

  1. Physical (केबल्स)

  2. Data Link (MAC एड्रेस)

  3. Network (IP एड्रेस/राउटर)

  4. Transport (TCP/UDP)

  5. Session

  6. Presentation (एन्क्रिप्शन)

  7. Application (HTTP/ब्राउज़र)।

Topic 4 शॉर्टकट कीज (Shortcut Keys)

F1: Help (मदद)

Deep Dive

फंक्शन कीज (Function Keys)

  • F1: Help (मदद)

  • F2: Rename / Edit Cell (नाम बदलें)

  • F5: Refresh / Slideshow (रिफ्रेश)

  • F7: Spell Check (वर्तनी जांच)

  • F11: Full Screen (पूर्ण स्क्रीन)

  • F12: Save As (सेव एज)

  • Alt + F4: Close Window (बंद करें)

  • Win + D: Show Desktop (डेस्कटॉप देखें)

शॉर्टकट श्रेणियां (Shortcut Categories):

• Navigation: Home (लाइन की शुरुआत), End (लाइन का अंत), Ctrl + Home (दस्तावेज़ की शुरुआत), Ctrl + End (दस्तावेज़ का अंत)।

• Formatting: Ctrl + B (बोल्ड), Ctrl + I (इटैलिक), Ctrl + U (अंडरलाइन), Ctrl + J (जस्टिफाई)।

• Browser: Ctrl + T (नया टैब), Ctrl + W (टैब बंद करें), Ctrl + Shift + T (बंद टैब फिर से खोलें)।

Topic 5 संक्षिप्त रूप (Abbreviations)

BIOS:* Basic Input Output System

Deep Dive

BIOS: Basic Input Output System USB: Universal Serial Bus PDF: Portable Document Format HTTP: HyperText Transfer Protocol HTML: HyperText Markup Language WiFi: Wireless Fidelity VIRUS: Vital Information Resources Under Siege GUI: Graphical User Interface JPEG: Joint Photographic Experts Group VPN: Virtual Private Network UPS: Uninterruptible Power Supply

संक्षिप्त रूप का महत्व (Importance of Abbreviations):

कंप्यूटर विज्ञान में संक्षिप्त रूप हर जगह हैं। उन्हें जानना न केवल परीक्षाओं के लिए बल्कि तकनीकी विशिष्टताओं को समझने के लिए भी महत्वपूर्ण है। उदाहरण के लिए, HTTP (असुरक्षित) को HTTPS (सुरक्षित) के साथ भ्रमित करना एक बड़ी सुरक्षा अवधारणा है। इसी तरह, BIOS को जानना बूट समस्याओं के निवारण में मदद करता है।
